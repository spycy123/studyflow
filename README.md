# 🎓 StudyFlow — Agenda & To-Do List Perkuliahan Modern

Aplikasi manajemen tugas, jadwal kuliah mingguan, fokus Pomodoro, dan simulasi target IPK yang dirancang khusus untuk mahasiswa dengan tampilan **modern, bersih, dan minimalis**.

---

## ✨ Fitur Utama

- 🔐 **Autentikasi Mahasiswa (NIM & Password):** Login portal akademik, registrasi mahasiswa baru, dan mode demo 1-klik.
- 📋 **To-Do & Deadline Pintar:** Kategori akademik (Tugas, Kuis, UTS/UAS, Laporan Praktikum, Skripsi, Proyek Tubes, Organisasi), indikator tenggat waktu relatif (*Hari ini*, *Besok*, *Terlewat*), checklist sub-tugas, serta tautan e-learning / Google Drive.
- 📊 **Tampilan Fleksibel (List View & Kanban Board):** Kolom visual status (*Belum Dimulai*, *Sedang Dikerjakan*, *Review*, *Selesai*) untuk pemantauan progres tugas.
- 📅 **Jadwal Kuliah Mingguan (Timetable):** Manajemen mata kuliah, ruangan kelas/lab, dosen pengampu, SKS, dan deteksi otomatis jadwal hari ini.
- ⏱️ **Fokus Belajar (Pomodoro Timer):** Dilengkapi fitur *White Noise / Rain Sound* bawaan berbasis Web Audio API untuk meredam distraksi.
- 🎯 **Simulasi Target Nilai & Prediksi IPK/IPS:** Hitung otomatis proyeksi indeks prestasi semester berdasarkan target nilai mutu dan bobot SKS.
- 🌓 **Dark & Light Mode:** Desain minimalis yang nyaman di mata untuk sesi belajar siang maupun malam hari.
- 💾 **Data Persistence & Cadangan JSON:** Tersimpan otomatis di peramban per NIM mahasiswa, lengkap dengan fitur Ekspor & Impor berkas JSON.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS + Plus Jakarta Sans Typography
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Efek Interaktif:** Canvas Confetti & Web Audio API

## 🚀 Cara Menjalankan secara Lokal

1. **Clone repositori ini:**
   ```bash
   git clone <URL_REPOSITORY_ANDA>
   cd jajal
   ```

2. **Instal dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan:**
   ```bash
   npm run dev
   ```

4. **Buka di peramban:**
   Akses `http://localhost:5173`
